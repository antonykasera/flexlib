# asm-audit spec: one function per line, checked in the -O2 Cortex-M3 objects.
#
#   <symbol>  [max=N]  [calls-ok | no-calls]  <mnemonic>...  [!mnemonic]...
#             [!call=symbol]...
#
# Every listed mnemonic must appear in the function, and none marked !x may. max=N caps its length in
# instructions, counting the return and not the alignment nops after it. A
# call to any `__` symbol (__aeabi_* soft-float, libgcc helpers) fails, unless
# calls-ok is given; no-calls fails any call at all (memcpy included). Calls are
# found from relocations, since `!bl` would also match the branch `bls`.
