# flexlib accuracy

Generated by `make accuracy` on the host: each flexmath and flexdsp function
and the CMSIS-DSP function it replaces (built from the same sources as the
bench), both against a `double` or exact reference. Errors are in LSBs of each
function's own output format, or ULPs for float outputs; bias is the mean signed
error. CMSIS-DSP is built with its default flags (no ARM_MATH_ROUNDING), as on
the bench.
